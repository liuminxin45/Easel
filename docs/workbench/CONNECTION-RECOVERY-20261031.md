# Windows 旧离线恢复页复核

用户报告 `/native` 显示“连接暂时中断 / 正在检查连接”。该文案来自已退役的根作用域 `/sw.js`，不是新版原生离线页。当前公网 `/native`、`/native/` 均经一次 303 到登录页并返回 200，带有旧恢复脚本要求的 `X-Desk-Architecture: toolbox`；缺失响应头和服务器持续不可达已在本机探针中排除，但这不代表用户浏览器的线路已恢复。

确定的问题是登录前的退役遗漏：业务入口精确注销旧根 worker，登录入口没有执行。因此未登录设备仍可能保留旧导航拦截。现将该逻辑收拢为私有 `retireLegacyWorker.ts`，登录和业务入口共同调用，只注销同源、根作用域、脚本为 `/sw.js` 的注册。不清缓存、草稿、附件、IndexedDB 或未知操作；原 Easel 页面、样式和后端不变。

真实归档旧 worker 在 TEMP Edge 中遇到 503 后会生成用户报告的页面。服务器恢复后，不人工刷新、更新 worker、点击重试或注入 online 事件，旧页约 5 秒自行到达真实候选登录页。修复前登录页留下旧注册；修复后注册消失，草稿、附件及两处未知操作记录保持逐字节一致。不能据此将用户现场持续卡住单独归因于已确认的登录遗漏；用户浏览器的实际恢复仍待确认。
