# 当天热点与空面板交付

需求：只展示北京时间当天实际采集结果，部分成功采到多少显示多少，空来源整块隐藏；完全未采到信息时保留面板外壳、内部留空，不显示提示，也不回退旧缓存。

## 实现

- 私有数据查询按当天真实采集批次/文章关联取结果，保留文章原ID、首次时间、历史批次和原文。历史浏览方法不变。
- 采集任务失败不再决定阅读页面是否显示有效条目；后台阶段记录和独立健康诊断保持真实。
- 官方DashboardPage仅增加默认原提示不变的可选空内容槽，私有入口传空；继续复用原TrendsPage与样式。
- 私有热点响应携带day/timezone，宿主同日复用缓存，跨日先清空旧快照/ETag再静默读取。迟到响应、304及已被淘汰的暖缓存均不得回填昨天内容。
- 解析器保留日期元数据，私有当天结果最多1000条；没有日期合同的官方原响应保持30条默认上限与原形状。
