# 移动会话产物、文字和返回路径修复

本轮按用户请求使用 Spec Kit，任务为 `mobile-session-navigation-20261031`，
选择锁定的 `speckit/workflows::engineering-change` 1.0.0。
原始请求、需求合同、实际执行回执和逐项验收记录在本机
`.specify/tasks/mobile-session-navigation-20261031/`；人工验收单独保留。

## 已复现的机制

- 390px 手机视口下，1086×4096 的测试长图实际显示为约 344×1297px。
  图片外新增的链接使原 `.artifact-stage > img` 尺寸规则失去匹配。
- 标题和正文使用字面文本的 `pre` 渲染，原来的 `white-space: pre` 使
  366px 区域出现约 7392px 的内容宽度；纯文本复制仍须保留原文。
- 产物原图和外部网页打开 `_blank`，新浏览上下文没有来源页面历史。
  外链改为当前上下文后，还复现了聊天区返回位置归零的问题。
- 消息操作依赖悬停显现，部分复制、素材和问答按钮只有 24–35px 高；
  横屏长图的链接区域还出现了约 43.42px 的宽度。

## 实现边界

- 在唯一共通样式中修复图片链接的尺寸约束，图片保留完整比例。
  窄屏为轮播箭头留出空间，原始图片与附件字节不变。
- 图片预览复用原 `ArtifactPreview` 和现有 `Modal`，接入
  `NavigationService` 弹层历史。界面关闭和浏览器返回均回到原会话；
  预览提供原图下载，保留现有焦点隔离与恢复。
- 移动端外部 HTTP(S) 页面、本机文件和 HTML 在当前浏览上下文打开，
  为系统返回保留来源。站内链接继续由唯一导航服务管理。
  下载、命名窗口、自定义协议和修饰键保留浏览器语义；桌面外部链接行为保留。
- 聊天的实际滚动容器登记为现有导航服务的滚动区域，等会话读回后恢复位置。
  返回保留未发送输入，不重复发送制作或平台操作。
- `CopyableText` 使用原按钮和产物头部样式，同一共通规则控制字面文本换行。
  Windows 剪贴板的系统 CRLF 换行在测试中单独记录，其余字符和渲染原文逐字核对。
- 窄屏触摸尺寸及消息操作可见性集中在原 `mobile.css`，使用现有主题与控件。
  输入栏以自适应分栏保留素材、提示和发送按钮，320px 下提示换行且不重叠。

## 验收范围

浏览器专项使用实际 Windows Edge、模拟手机及触摸事件、TEMP HTTPS 服务器，
测试横图、方图、长图、标题正文、复制、图片及原文件入口、外链与本机网页往返、
弹层关闭、草稿与滚动保持，以及 320/360/390/430px、低高度横屏和桌面、明暗主题。

原逐页清单覆盖工作台、热点、选题、日历、素材预览、作品和记录、技能、画像、
账号、发布、统计、对话及弹层；设置另跑引擎、六通道、模型下拉、环境、
嵌套选择器、焦点循环和模拟键盘高度变化，导航关闭另跑来源恢复专项。

所有原始失败、诊断、最终报告和截图保存在
