# 移动端返回与生命周期整改

本轮落实 `mobile-return-state-20261102` 的三批整改。官方基线仍为
`0f43dc98277eac85fb48952878acad349731d3fc`；共通页面继续引用同一个 Easel
实现，宿主集中提供缓存、UI 元数据、草稿、导航和生命周期端口。

## 第一批：返回、滚动与输入

| 问题 | 实现与边界 |
| --- | --- |
| M01 原页面返回重新空载 | 普通 GET 接入现有资源缓存，原组件从快照首次呈现，再订阅刷新；敏感账号、凭据、二维码和回执仍直接核对服务器。 |
| M02 筛选等丢失 | 原页面可选 ViewState 端口保存筛选、目录、月份与查询；按历史条目隔离，模块重入使用最近状态。 |
| M03 滚错容器 | 导航找到实际页面滚动区；聊天声明自己管理消息滚动，避免两套恢复逻辑竞争。 |
| M04 内容未就绪就恢复 | 非零位置等待匹配条目的内容或实际滚动范围，用户触摸后停止补偿；旧页面的迟到回调不能控制新页面。 |
| M05 热点嵌套滚动 | 纠正原审计推断：解析器原本每源最多30条，不存在已证实的1000条渲染问题。只移除移动端内层限高和滚动阻断，不增加列表分页控件。 |
| M10 聊天自动拉到底 | 记录阅读位置与是否跟随末尾；上翻阅读时追加消息不抢位置。 |
| M17 未发送输入 | 继续使用原获准草稿仓库，日历和技能执行输入接入原端口；迟到保存结果不清除后来编辑。密钥只留当前组件内存。 |

## 第二批：缓存、调度与有界读取

| 问题 | 实现与边界 |
| --- | --- |
| M06 每次保存检查版本 | 版本探测合并、最短间隔30秒；触摸/输入后至少安静10秒，正在编辑、未决回执、设置或弹层期间不热切换。 |
| M07 各页轮询间隔失效 | 同资源共用调度器，遵守实际最小订阅间隔、单飞和失败退避。 |
| M08 隐藏页仍轮询 | 普通资源、扫码和安装状态隐藏时暂停；恢复先读取原状态，不创建另一操作。 |
| M09 无差别失效 | 按已有资源标签精确失效，移除重复全局刷新；401清除私有读缓存和视图快照，保留输入和附件。 |
| M13 会话列表和完整历史 | 列表汇总不逐会话重建正文；页面使用最多50轮的历史窗口，旧窗口只读。内部完整历史/存档接口不截断。 |
| M14 反复草稿广播/扫描 | 相同持久化状态不广播；待决扫描按草稿修订缓存，原回执身份不变。 |
| M18 升级抢焦点 | 新版本仅在安全空闲时切换；仍有输入、弹层、未决操作或保存错误时延期。 |

业务响应只存有界内存。导航的 URL、滚动和筛选元数据可存 history/sessionStorage，
导航条目、位置和视图存储均有上限；不将历史正文、账号资料或密钥放入该存储。
缓存过期、被逐出或应用进程退出后允许重新读取，不能承诺永不请求服务器。

## 第三批：弹层和平台边界

| 问题 | 实现与边界 |
| --- | --- |
| M11 Back 和未保存编辑 | 侧栏、原扫码框和凭据框接入唯一导航层；Back优先关闭当前层。设置变更离开时确认，同页设置分区切换保留编辑。 |
| M12 外链/文档离开应用 | 外链使用独立浏览上下文；同源白名单文档复用原 Drawer/ArtifactPreview，空 sandbox，不另建弹窗体系。 |
| M15 日历错误静默 | 创建、修改、删除失败在原页面可见，原输入不丢失；排期不扩大发布授权。 |
| M16 紧凑布局分歧 | 宿主统一使用900px及矮屏横向条件，原组件默认断点不改；只在宿主局部样式作用，不增加顶部导航横栏。 |

已被服务器受理的安装任务继续由原持久队列执行；批量安装中尚未发出的工具，
离开设置后不再发送。这里没有新增可在卸载后继续提交的批量队列。
