- 今日热点摘要在移动端使用原组件默认平铺，移除套在短列表外的滚动容器；热点长列表允许到边界后继续滚动页面。没有增加触摸或滚轮事件拦截。

- 私有聊天投影在草稿输入和相同消息轮询时保持消息引用，避免触发原组件的重复自动滚动。
