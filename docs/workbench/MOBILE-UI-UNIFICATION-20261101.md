# 移动端页面与弹窗复核

Spec：`mobile-ui-unification`。官方基线：`5a597e5f3ef5b01098b53f36caf719dd9a32b7bf`。

## 目的与范围

逐页核查工作台、新闻、选题、日历、对话、技能、内容、账号、画像、发布、复盘、
设置和本机输入，包括详情、弹窗、菜单、明暗主题及手机、平板、横屏。
继续使用原 Easel App、页面、设计 tokens 与控件，不建立另一套 UI。

## 已修复

| 问题 | 处理 |
|---|---|
| 新闻原文页缺少滚动容器 | 直接使用原 `page-scroll`；保留原文并验证末尾及做内容入口真实可达 |
| 同一中断版本重复提示 | 同一版本只保留一个 TaskStatus；保留原记录、文件及服务器确认的继续路径 |
| 技能发布最多叠三层弹窗 | 在同一 Modal 内切换详情与确认，差异就地展开；返回保留输入、范围、焦点及阅读位置 |
| 斜杠菜单显示默认黑边按钮和长说明 | 从原画笔提取唯一 BrushItem，两入口共同使用原列表样式与截断，保留键盘和不自动发送语义 |
| 平板菜单越出主区、横屏向上越界 | 宿主按 composer 可用宽度适配；两菜单共用 useBrushPopover，只在实际越界或内容挤压时修正 |
| 很矮的可见视口挤掉菜单列表 | 使用原面板整体单滚动回退，不隐藏控件或缩字体；关闭或恢复视口时还原样式 |
| 首页、标签、来源选择等触控区域过小 | 只调整宿主移动几何，主要动作高度 44px；保留原生开关等 24px 控件，不另画样式 |
| 技能首次读取误显“没有匹配”的空列表 | 原 SkillPage 区分初始读取、真实空列表和错误；已有卡片后台刷新保持，不闪刷新提示 |
| 主按钮悬停白字浅底 | 原 `.btn-primary:hover` 仅补回既定背景，避免通用 hover 覆盖 |
| 复盘页重复导航 | 删除私有内层 SubNav，仅保留原 App 导航 |
| 日期要求手机手输 ISO | 原生 datetime-local，集中转换；未编辑保留原串，未知仍留空，原授权确认不变 |
| 宽屏私有弹窗关闭按钮另起一行 | 仅在 ew-dialog 标题区补齐原有 flex 几何，短标题和关闭按钮同排，长标题可换行 |
| 本机输入直接显示存储键 | 只改标题呈现，优先显示内容，其次使用类型名；原键、原文和详情保留 |

界面启动异常的详情入口也改用既有按钮，不再显示裸默认三角。
原内容库的普通下载链接沿用 Easel 原呈现，不用私有 CSS 改写通用链接。

## 共通与私有边界

必要的共通改动集中在原画笔、聊天、技能页和一条按钮规则，独立提交；
公共组件与位置逻辑不依赖私有模块。私有记录、版本、时间输入及草稿标题仍在
`web/frontend/src/workbench/`，使用原组件及 tokens。

新增的 `components/useBrushPopover.ts` 在架构检查中按准确文件名登记，不放宽相邻目录。
其必要性来自 844×390 的真实菜单 top=-69/-47 及很矮视口列表挤压证据；
普通布局已在可见范围内时不改定位，公共部分可独立复用。

源码仅推送自有 fork。并行的后端 P0/P1 架构改造与复核单独提交，
不随本轮前端切换启用新后端。
