# 原生内容库与成品接收

Spec: [native-product-experience](../../specs/native-product-experience/spec.md)

原生ChatPage负责讨论和制作，原生OutputsPage负责全部产物浏览。移除私有作品浏览画布、查看产物和复制图文按钮，以及输入框下重复的关联作品按钮；正文中的普通超链接进入准确版本内容库。版本操作在官方扩展位默认收起，继续复用原生控件与原服务器事务。没有增加HTML操作页或平行模型传输。

当前案例回合 `a02464b3-c48e-4c61-b8b3-aa405a9e1de7`：模型与hook已完成，但Markdown中的`/D:/...`不能被原Windows文件路径读取，artifacts为零。统一接收入口规范化URI、盘符与编码，继续只接受明确文件、准确本轮目录及原字节；目录链接不授权扫描邻居。正式补登记由准确预览SHA约束，在部署停写后调用原确定性接收器，追加原失败证据与纠正回执，不调用制作模型、不修改原文件。

图片、文档、预览、下载、版本入口与返回复用官方组件；最终文件和过程材料分区。尚未完成的材料可通过原只读文件合同查看，不冒称成品或检查通过。采纳与分发保持原来的独立检查和明确授权。

真实Edge桌面与360/390/430模拟移动布局验收覆盖长标题、原生文件下载、默认收起、精确版本修改、不采纳、短视口输入与历史链接刷新；完整内容闭环仍验证采集、制作、独立检查、采纳、下载归档及原始附件。模型执行器为TEMP假执行器，不代表真实模型质量或实体vivo/WebToApp验收。原生侧栏和文件预览使用同一通用实现，通用模块没有私有服务依赖。

本轮证据位于 `.local/workbench-validation/native-product-experience-20261102/`。正式配对、最终检查及上线结果在验收后补记，用户实际改后反馈仍待提供。
