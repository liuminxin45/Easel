# 新闻详情与原生创作接入

2026-11-03 已上线。新闻详情是私有业务入口，创作仍使用 Easel 原生会话、技能、请求受理、回执和内容库；抽屉与选择控件直接复用官方组件。

## 使用方式

- **讨论怎么写**：首次直接发起普通讨论，不生成贴图或完整文章。后续点“继续讨论”返回原会话，不追加重复请求。
- **制作内容**：选择贴图或文章，再选择风格并直接开始。贴图明确选择写法、视觉、角色和版式；文章必须选写法，插图按需附加。
- **同一会话继续制作**：会话中的“新闻详情”“制作内容”承接讨论，沿用原画像和会话。
- **默认风格**：仅点击保存时按画像、内容形式保存；本轮调整不改默认。旧作品和历史选择不自动成为默认。
- **历史材料**：本轮原始材料清单和 SHA 保留；2026-11-04 按用户要求移除了会话中的“本轮创作设置”入口及抽屉。

自然阅读正文与“采集记录”分开；原始采集文本在官方 Drawer 内保留。移动端底栏按钮高 44px，正文为既有悬浮导航保留私有安全边距，没有改写官方侧栏布局。

## 实现与边界

私有服务为 `easel_workbench/features/news_creation.py`；前端集中在 `web/frontend/src/workbench/ui/` 的新闻组件。轻量 creation-context 不返回全文、提示词或资源二进制，参考图单独按需获取；共用资源缓存按新闻和画像变动失效。

生产明确调用原生 `content-production`，通过 SKILL 组合写作、图片和审核能力。角色参考实际复制到本轮普通输入附件，记录准确文件 SHA；文章不强制生图。API 模式或只读 Codex 会话不能执行制作，保持原权限，不自动提权。

新增新闻/画像到会话的关联表及可选画像默认字段。归档或删除后须明确重新开始；未知回执只核对，不重发。没有恢复私有经验、候选技能、版本发布或计划审批。

目录中 12 个旧提示词摘要与原文件不符，本轮核对文件未变后修正目录摘要；原文本及图片均未编辑。详细证据见 [资源摘要校准记录](news-creation-resource-rebind-20261103.json)，历史冻结副本保持原样。
