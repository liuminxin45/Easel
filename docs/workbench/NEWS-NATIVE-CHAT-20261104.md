# 新闻会话恢复原生交互

2026-11-04 已实施并部署。会话底部常驻的“新闻详情”“制作内容”按钮及其制作抽屉已移除。相关用户消息旁显示带下划线的“这条新闻”链接；制作通过官方画笔或斜杠选择技能、输入要求并明确发送。选择技能不会自动发送或弹私有设置。

官方 ChatPage、MessageBubble、技能选择组件均未修改。消息链接使用既有消息扩展槽，普通点击沿用应用导航，修饰键点击保留浏览器标准行为。仅有可核实回合来源时显示链接，不改写历史消息正文。私有新闻页原有讨论、制作、采集记录入口保留。

## 材料与状态

- 后续回合从服务端会话继承新闻来源，实际原文固定为本轮附件；API 仅聊天模式从同一材料包核对 SHA 后内联原文，不依赖模型访问登录页面或读取本机文件。
- 选择原生内容生产技能时，画像显式保存的风格默认和真实参考文件作为建议传入，本轮原话优先。格式未明确、默认缺失或槽位不完整时由原生 Agent 询问，不从标题或默认值猜格式，不同时制作两套。
- 首次“只讨论”仅限制该轮，后续明确选择制作技能可以继续制作。普通修改继续引用新闻，不重新附加当前画像默认以覆盖已有作品要求。
- 材料按本轮身份固定，重试不重新解析当前默认或原文；原 HTTP 请求签名和回执身份保持。归档、API 制作限制及只读会话权限继续核验。
- 没有恢复私有技能版本、经验或计划执行器，没有迁移历史数据。
