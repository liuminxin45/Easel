# 私有页面分层读取（2026-11-03）

## 已确认的负担与处理

以下旧版数据为一次真实鉴权 GET 的观察，不是压力基准；没有保存业务正文。

| 页面／请求 | 旧版观察 | 本次私有实现 |
|---|---|---|
| 技能库 `/api/skills` | 135 KB、11 秒；列表背后重建全部资源包和历史版本 | SQL 只投影版本身份；已校验的不可变包用 manifest 元数据生成目录，内容寻址缓存只保存摘要；点击技能才读所选正文与配置，显示详情也不带整套执行依赖，受理仍校验实际字节 |
| 全局 creator bootstrap | 91 KB；附带完整画像、资源、差异与所有版本 | 壳、新对话、拆解采用 `view=summary`；技能描述由 SQL 直接投影，画像绑定展开后只读准确当前画像，完整编辑和技能执行保留独立路径 |
| 经验中的作品选择 | 154 KB、12.4 秒，关闭区域也读取 | 展开才请求每页 50 条作品摘要；游标绑定筛选；跨页保留所选作品 ID |
| 作品详情 | 单作品单版本 1.73 MB、5.36 秒；冻结执行快照在历史和版本重复 | `/works/:id/view` 只读草稿与版本目录；`/versions/:vid/view` 只读准确版本；`include=history` 显式展开后读取；制作参数仍由准确 prompt 接口加载 |
| 发布台账 bootstrap | 607 KB、46 秒，含全部作品／版本／规范／记录正文 | `view=publications` 只读台账元数据；按 ID 打开原抽屉才读完整记录 |
| 分发 bootstrap | 302 KB、5.56 秒；每条修订均验证，包含全部正文／回执 | `view=summary` 只投影元数据和计数；批准前单独读取并验证准确修订 ID／hash／有效性；回执只按准确 ID 读取 |
| 选题与画像列表 | 返回很小，但后台构造所有作品／完整技能 bootstrap | 直接查询所需作品状态／画像；不绕行完整业务投影 |
| 所有私有扩展区与记录抽屉 | 关闭只隐藏 DOM，仍挂载 hooks／轮询／格式化 | 首次打开才挂载；关闭暂停读取与轮询，保持草稿；嵌套可见性取交集，长 JSON／文本打开抽屉才格式化 |

摘要不代表可采纳或可发布。准确原文、父版、画像修订、技能 SHA、原始反馈、未知回执和授权事务均继续走原权威处理。分页和重开页面不会发送模型请求，也不会重放未知操作。读缓存的 key 包含 query；元数据视图不再为签名遍历全部产物或规范。

## 范围与兼容

逐项审计覆盖六个主入口、雷达／资讯／选题／排期／发布／拆解以及私有版本、经验、反馈、交付、配置、恢复控件。热点正文、画像文件、聊天历史窗口和内容库本来已经分层，保持既有语义。来源、账号、模型与设置等小型必需目录没有机械分页。退役的生产／学习界面不因本次优化重新启用。

旧兼容接口保留给原调用方；私有调用改用明确的摘要与详情端点，禁止先构造完整对象再切片。官方发布页的媒体选择器仍调用原 `fetchOutputs`，没有宿主分页接口。本次用户指定在私有代码修改，该共通组件的例外已单独询问，未擅自修改，也不把其全树请求冒称已经消除。

旧 `/api/creative/bootstrap` 的 400 来自历史技能版本不包含旧创作方案目录。没有给历史版本补入今天的文件或恢复退役流程；关闭的兼容扩展不再触发该请求。

## 验收与交付

实现验收：609 项前端测试，228 项相关后端测试，原 Easel build、工作台类型／交互／基座检查通过。新增 TEMP 测试直接禁止重对象构造、比对旧权威身份和状态、验证未知回执不重放、同大小同 mtime 字节变更不可冒充相同技能、冻结目录摘要与实际 release 身份一致。

自有 fork 的移动状态 CI 增加这些回归；未声称远端 Actions 已通过。原始测量、后续冻结浏览器验收与上线证据集中在 `.local/workbench-validation/private-lazy-pages-20261103/`。最终配对版本、HTTP 测量和交付 SHA 在上线后补记。浏览器移动视口不等于实体 vivo WebToApp 验收。

R1浏览器发现的阻断已记录：技能抽屉内创建会话的 `navigate:false` 被800ms进度计时器忽略，任务问题因此不可见；修复集中在私有 SessionOpenFlows。新增侧栏删除恢复原按钮／确认框，私有后端做幂等历史保留标记，进行中／未知回执不得删除；删除当前会话后回工作台，不自动创建对话。R1候选未上线，需R2重新验收。
