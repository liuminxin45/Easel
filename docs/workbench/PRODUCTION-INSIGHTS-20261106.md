## 使用

1. 新的油猪·做贴图/做文章完整交付后，后台按准确版本整理相关会话和真实成品。打开内容库的准确版本，在“版本与操作 → 制作复盘”逐条核销。学习技能不触发此流程，旧历史不自动重跑。
2. “同意，待实施”不会修改技能。技能规则调整仍需明确开发指令、提交及验证；实际落地后凭准确证据核销。用户后续采纳、拒绝与原话反馈增量进入每技能总记录，不重复调用模型。
3. “优秀模板”中明确填写方法、规范，选择准确参考并确认保存。可逐条勾选已经落实的建议，只有核对真实模板后才标记落地。模板和建议核销分别保留真实结果。
4. 下次在原“制作内容”抽屉明确选择优秀模板；展开详情才读取方法，实际开始时冻结修订和参考。格式、画像和技能隔离，允许明确覆盖本轮风格；默认预设与恢复上次风格保留。
5. 手动在公众号后台发布后，将原文URL关联到准确版本；每天北京时间09:00只读刷新已绑定作品，也可手动刷新。原生登录失效须在“账号”页扫码。URL/平台身份精确关联，不按标题推断；真实零值、缺失和PV/UV分别记录。

总文档为私有数据投影：`data/production-insights/oil-pig-poster.md` 与 `oil-pig-article.md`，首个复盘完成后生成，也可在复盘抽屉查看。它们不是已生效的技能正文，不写进冻结SKILL。模板与私有队列放在同一私有数据域，发布事件/统计快照仍复用官方 `skill-publish-log` / `skill-data-tracker`。
