## 使用

在本项目的新一轮 Codex 对话中调用：

```text
$speckit 按当前项目约定完成这项需求，并给出验证结果。
```

技能和上游文档中的 `specify ...` 均改用本项目包装入口：

```powershell
pwsh -NoProfile -File ./scripts/specify.ps1 --version
pwsh -NoProfile -File ./scripts/specify.ps1 pack doctor --json
pwsh -NoProfile -File ./scripts/specify.ps1 context --json
```

包装入口始终以项目根目录运行，临时为子进程选择同一项目 CLI，
并透传参数和退出码。机器现有全局 `specify 0.15.1` 保留，裸命令仍指向该全局版本。

## 复装

```powershell
pwsh -NoProfile -File ./scripts/install_spec_kit.ps1
```

需要 PowerShell 7、uv 及现有 `.runtime/workbench-python/Scripts/python.exe`。
其他检出可通过 `-PythonPath` 显式指定已有 Python 3.11+；脚本不安装或替换 Python。
复装按固定版本同步独立依赖，使用锁文件恢复缺失的内置包缓存，
再检查版本、`pack doctor` 和 `context`；保留用户定制，不自动初始化或升级项目。
包缓存、事务和锁目录由 Spec Kit 自身加入 `.gitignore`，无需提交。
