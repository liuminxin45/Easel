# 后端回归的保留与退役

用户已明确要求业务技能采用 Easel 原生流程，不再通过私有制作方案、自动评审、经验提炼和技能版本编排执行。本目录保留变更前五份测试原文，追加 `.txt` 后缀避免仓库根目录 pytest 将历史规范重新收集为现行需求。`backend-original-sha256.json` 以原文件名记录归档时字节 SHA256；原文没有删改。

现行测试没有通过跳过断言或恢复已退役的 `confirmed()` 方案入口来变绿：

| 原测试文件 | 现行覆盖 |
|---|---|
| `test_workbench_chat_responsiveness.py` | 继续实际测量原生列表、历史、技能目录的并发健康请求；保留 SQLite 受理提交与任务发布间隙的所有权、重启未知状态、提交回滚和应用线程问答 Future。只将旧方案 I/O 换成当前技能目录 I/O。 |
| `test_workbench_chat_products.py` | 原生成功／中断回合真实 TEMP 文件、精确标题正文、只读投影、文件内容变化、回合隔离及私密文件／路径链接拒绝继续测试。普通原生结果不再伪造私有作品和采纳身份。 |
| `test_workbench_delivery_reconciliation.py` | 改用明确持久化的历史失败接收记录；测试预览只读、原文件 SHA、停写围栏、字节变化拒绝、未知状态不重放，以及部署验收必须绑定准确预览。原测试中的新私有制作和成功自动接收／采纳编排只保留原文，不再作为新流程要求。 |
| `test_workbench_native_completion.py` | 测试持久化历史作品的准确版本、原始决定与正文、完成选项只读和外来版本拒绝。旧“新建私有制作→自动质量检查→采纳→归档”完整编排已退役；不调用模型或新制作来制造历史。 |
| `test_workbench_native_corrections.py` | 保留历史非排队／未知任务重启不重发、后来用户输入仅取代未发送任务、停写拒绝发送、父冻结字节／记录哈希损坏拒绝，以及受理完成后不得被晚到元数据错误取消或重新排队。旧“新制作→自动纠错→私有子版本”不是当前入口能力。 |

此外，现行 `test_workbench_version_view.py`、聊天历史窗口／原生回执、原生引擎 RPC 测试以及新的官方技能服务测试分别覆盖历史字段保持、分页、未知执行不重放和原引擎调用。归档文件用于说明之前的行为，不能当作本次真实模型质量或平台交付验证。
