# 角色三视图的设计取舍

Design Read：已认可小猪侠形象的动画角色设定三视图，保留实际附图的身份与粗黑手画线，统一比例与视角；以复用为目的。Dials：DESIGN_VARIANCE=2（保持角色、对齐基线）、MOTION_INTENSITY=1（静态设定）、VISUAL_DENSITY=3（三个视图）。

本轮不继续探索新脸型或画风。来源权威是已认可正面参考.png，按原图保持耳朵高低、猪鼻、头身比、点眼睛与偏侧微笑。横向正/侧/背，严格同高、同线重，侧面90度、背面180度，身体无衣、无帽，红色只有一笔飘线。固定围巾自由端为角色自身右后侧，随转向改变画面位置；背面小卷尾为本轮正常视角延展，未声称用户原图已明确。实际提示词已在生成前确定并交给内置imagegen。

正面身份已认可，新增侧背与三视图编排完成后供用户核对。角色源素材不加发布水印；复用于贴图成品仍按图片制作要求使用油猪大侠水印。此设定不会直接替换Tech Pulse等既有版式母版。
