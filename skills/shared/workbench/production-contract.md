# Easel 项目内容工作流

通过 Easel 原生技能调用接收本轮用户输入与画像；按任务需要读取项目 SKILL 和相应资源。不存在必须取得的私有制作计划、候选发布指针、试用版本或业务 hook。

1. 先核对主题、目标读者、格式、来源和用户指定的原文；缺关键输入时在当前原生对话询问。
2. 内容生产按需组合 content-writing、image-production 与 delivery-review；组合步骤由 SKILL 定义，跨层沿 Easel 原生 manifest.py 记录路径和简短结论。
3. 产物写入 outputs/<主题>/，提供真实图片、正文和可打开的文件路径。只讨论时不制作；按量计费操作沿官方规则先确认。
4. 修改时读取用户指明的原文件与意见，保留原件另存修订；不猜测不存在的版本、来源或回执。
5. 交付前实际查看文本和图片，记录可复核的问题；检查通过不代表用户采纳或发布。
6. 用户反馈用于本轮明确范围，不自动整理经验、创建技能候选、改画像或长期规则。发布、账号操作及外部写入必须另有明确授权。

既有冻结输入和历史资源只作准确历史依据，不执行旧私有API、外项目脚本或归档流程。普通技能执行不伪造已采纳、已归档或已交付到平台的状态。
