# 文章参考与个人风格学习操作

适用收集／收藏文章、拆解、比较同类、整理反馈，以及正常文章写作的取材。规范读[写作要求](../../../../规范/写作要求.md)和[存档规范](../../../../规范/存档规范.md)；材料入口为[研究README](../../../../资料/风格研究/README.md)与[样本索引](../../../../资料/风格研究/样本索引.md)。

## 收集和拆解

1. 先查样本索引，识别同篇重复和版本关系。用户附件保存原字节并核对SHA-256；外部参考留在风格研究的单篇目录，自己的文章只链接其内容档案。保存本轮完整指导及实际来源、取得日期、材料完整性。
2. 默认按[分析模板](../../../../资料/风格研究/分析模板.md)简析。主类由文章任务决定，主题、叙事和语气另加标签；材料不足注明缺失。明确请求拆解、特别关注或带来新方法时精拆，修订分析另存具体版本。
3. 精拆说明内容贡献、结构论证、故事、调侃与呈现、方法及条件。自己的文章先读档案、进度、原始反馈、构思和最近修改记录；反馈为空就找实际讨论来源，复盘辅助定位，不以摘要代替原话。
4. 更新索引和相关类型笔记；样本编号稳定，同篇修订不新增计数。新原件、分析及反馈入口要能跨聊天找到。

用户提供为主。按需补充网络材料时使用当时可用的来源获取流程，保存取得范围；没有全文就不声称读过全文。不因收集请求而自行扩展为批量抓取或调度。

## 链接文章的浏览器读取

材料获取执行[写作要求中的浏览器优先规则](../../../../规范/写作要求.md#文章学习与个人风格演进)，依据[2026-10-11完整指导](../../../../资料/风格研究/2026-10-11-文章链接优先内置浏览器.md)。本流程已有用户获取方式偏好优先于通用网页抓取建议。

1. 打开用户提供的具体链接；已有对应标签则复用。用户要求展示时保持可见，一般取材按浏览器默认方式操作。
2. 先核对页面标题、作者、日期与正文是否出现，再与样本索引核对同篇关系。链接仅用于验证打开能力时不擅自新增精拆或计数。
3. 从实际页面读取正文与小标题，按需滚动和查看图片；区分页面结构中列出的图片与实际加载、可读的图片。只看到了标题或前几段，就记录为局部材料。
4. 需要学习存档时，在同篇保留原链接、可取得正文与媒体、取得日期和实际完整性；保存的材料排除页面会话和认证字段。已有下载文件、截图与浏览器正文分别标明来源，不互相冒充原件。
5. 遇到登录、验证、页面不可用或缺失媒体，记录当时实际状态；需要用户操作时说明具体原因。可接续已有本地材料，不能静默改用直接抓取，也不能将浏览器打开成功等同于全文、全部媒体或外部事实均已核验。

## 比较同类和整理反馈

先读取索引找到候选，精读本次覆盖样本，不加载整个参考库。比较文章各自解决的问题、方法差异和适用条件，更新类型笔记并记录覆盖编号、日期、计数。累计与收尾规则执行写作要求；尚无多例时明确是单例观察。

整理反馈保留完整原话和原附件，链接实际版本及段落；记录修改前后、原因与范围。如果只是分析没有改稿，就明确这一点。用户明确通用要求更新唯一规范，候选和局部认可保持实际身份。新增正向例段须有相应原始认可依据。

## 正常写作怎样调用

写作前读取写作要求、相关类型笔记、[作者素材索引](../../../../资料/风格研究/作者素材索引.md)，再选择少量原始材料核对。没有该类笔记时按材料组织，不要求先补齐研究库。

通常选一两种适合本篇的方法在草稿里试用；它们是帮助组织材料的选择，不是固定标题、篇幅、段落或调侃配额。在本篇制作／修改记录注明材料入口、方法、选择理由及认可范围。外部事实重新核查，自己的经历不增加无据细节。

后续用户自然评价即可，Agent负责对应到版本、整理差异并更新材料。读者成品里不放制作说明。收集与学习没有授权发布、自动推送或模型训练；Git仍按此次任务实际授权处理，贴图已有独立收尾合同不扩展到学习档案。

新制作同时执行[标题与配图反馈检查](../../../../规范/写作要求.md#标题与配图的反馈检查)。[反馈检查案例](../../../../资料/风格研究/反馈检查案例.json)只索引有原话、版本与适用边界的正反例，不新增文章精拆计数，不把助手改题当认可正例。收到新反馈后按同一规则增补/修正案例，原证据保留；可在本篇保存带精确引文的检查观察，以区分重复问题、明确正向例子和无法判断，分类仍是助手解释。没有用户反馈就保持待观察，不把自审、沉默或生成结果记成进步。
