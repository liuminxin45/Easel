# 图片制作要求

## 个人标识与水印

“油猪大侠 / 油猪”是作者的自媒体个人标识。图片成品水印统一使用“油猪大侠”，不使用“neo.io”；“油猪”为个人标识简称，不自行替换默认水印。适用于贴图、公众号及其他自媒体图片，项目目录和技能名称保持原有名称。

水印放在不遮挡主要信息的位置，保持手机尺度可读。原帖、工具实测等截图原件保持原貌；需要水印时添加在成品图解的独立区域，不覆盖原作者身份和来源。历史成品保留原件，重新交付时另存版本并采用新水印。

Tech Pulse／科技脉搏封面固定以“油猪大侠”四字作为页眉，与日期形成轻量标识区，避免遮挡栏目标题或在底部重复水印。这是用户明确的封面标识要求，当前候选构图仍须评审，不自动替换其他内页或整套默认模板。[完整指导](../内容/Tech%20Pulse-2026-10-13/用户指导-油猪大侠固定页眉-v03.md)。

## 角色与内容的关系

### 具象小猪场景优先（2026-10-23）

用户[明确选择与实施授权](../资料/风格研究/2026-10-23-用户任务与小猪场景风格/用户原话.md)将“具象小猪场景”作为后续文章与贴图自制主视觉的优先方向。先明确用户任务，再设计小猪对什么对象采取什么动作、改变哪一步或产生什么结果，让画面解释麻烦与解决方式。按[写作规范](写作要求.md#用户任务与技术解释2026-10-23)客观表达技术，不用通用科技装饰代替具体用途。

角色身份、红围巾及可爱感保持，颜色、环境与道具依主题选择，延续清晰、干净、适度字号与明确主次。真实界面、输出、对比和技术图解在需要解释细节或提供依据的位置使用；保持来源原貌，不以插画模拟产品真实结果。优先检查现成材料是取材核查顺序，最终主视觉按本节确定，不自动把现成图排在首位。

小猪不必在每页重复出现。逐图写清“这页增加什么理解”，重复动作没有新作用就删除，允许留白。动效用于展示过程或状态变化，标题与关键说明保持稳定可读。张数、动作、字体、配色和比例不设固定配方。长文封面继续默认无字；已认可固定栏目母版和官方原图不强加角色，历史成品保留。

## 首版视觉方向

公众号通用自制封面优先采用具象小猪场景，用具体对象、动作或结果表达本篇用户任务。保持克制的编辑插画、明确主体与适量留白，配色依题材选择；抽象意象按解释作用使用，避免通用机器人、发光大脑、霓虹科技图。

公众号长文封面默认无字，除非用户或单篇需求要求文字；这一默认不适用于贴图首图，贴图首图按贴图规范显示完整标题。有字时保存准确文案并核对生成文字。关键主体考虑封面裁切和缩略图阅读。同篇多图保持色彩和视觉语言一致，允许单篇需求选择不同风格。

贴图以内容表达为先，通用自制主视觉执行本规范的具象小猪场景优先；照片、信息图、原帖和真实界面按其信息作用采用，不要求每页都用插画。文字贴图应保证手机可读，事实信息可追溯。

## 官方现成素材与个人表达

决定画面前，先检查直接来源中的图片、Logo、产品名称与slogan、功能卡片、表格、流程和演示，包含README与其链接的assets。准确、易懂且适合手机阅读的材料，按真实界面、结果、证据或补充解释的作用采用；通用自制主视觉按[具象小猪场景优先](#具象小猪场景优先2026-10-23)表现任务，也允许原图直接承担合适页面，不为同一信息重复制图。原图保留原貌，核对链接、版本、数字、支持范围与条件，不能因官方来源就省略核查。具体图形出处尚未确认时，区分内容有依据与原图片已核实。

个人标签不需要强到压过产品。自制封面可使用官方Logo、名称与一句定位，保持与所用素材协调，继续遵守首图标题要求；原图不适合作首图时可作为后续配图。直接使用官方图时不强行套个人品牌色或覆盖原图加水印；需要个人标识时放在独立轻量区域，名称仍为“油猪大侠”。个人判断也可通过选题、素材选择、顺序与配文表达，不要求每张图有额外观点。

简约以理解效率判断，不以字少或图少判断。保留有助于理解的流程关系、能力差别和必要条件，删重复说明、制作信息和装饰。现成图的自然比例按可读性保留；自制场景与现成图分别承担任务解释和细节依据，不全部重画。四张参考、全英文封面及手绘风格都不成为固定结构；已认可固定栏目母版按其原范围执行。[完整指导及四张参考](../内容/腾讯开源TeamAI/参考资料/2026-10-11-官方图解参考/用户指导原文.md)、[与上一版的对照](../内容/腾讯开源TeamAI/学习记录-官方现成图解-2026-10-11.md)保留。

## 图文版面的层次与节奏

“统一边界与对齐”指安全边距、网格和内容块内部的秩序，不等于所有元素共用一条左边线。避免为了整齐，将标题、说明、数字、截图与脚注机械地同轴、同宽并以相同间距反复堆叠。左对齐仍可使用；按内容角色安排视觉焦点、大小比例、图文关系和疏密变化。

标题与主视觉先建立主次，辅助解释靠近对应内容，来源及水印轻量收尾。图片外沿、文字起点和块内留白按实际关系处理，可以选择内缩、分栏或居中，表格与列表保持自身块内的规整对齐。变化须有信息组织依据，不靠随机错位或额外装饰制造设计感，不强制每页非对称或每块换对齐方式。

留白须服务视觉重心、主次及内容关系。删减文字后同步重排内容位置、图形尺度和间距，检查固定页脚或旧布局是否留下无功能的大段空白；不能只删字而保留原来预留的洞。内容少时优先让关键图形形成明确主视觉、收拢相关内容，避免分块平均摊开，不用无用文案或装饰填满。程序无溢出、文字清楚之外，实际目视还须检查整体内容是否松散、空白是否有构图作用，不设固定留白百分比。[完整本次反馈及实际范围](../内容/美国年轻程序员就业与培养断层/用户指导-空白过大与构图-2026-10-12.md)。

检查时除边界和溢出，还要实际看手机尺度下的视觉重心、留白节奏、中文断行、图文比例与阅读顺序。现成设计技能、系统与样图作为有适用范围的参考；未获认可的字体、动效、具体版式和模板不得自动替换现行母版。完整依据见[本次用户指导](../内容/Karpathy谈AI认知差距/用户指导-版面过度左齐与设计参考-2026-10-12.md)，参考选择见[设计研究](../资料/风格研究/2026-10-12-贴图版面与设计参考/分析与选择-v0.1.md)。

## 图片优先的贴图制作

### 标题与配图的反馈检查

共享流程执行[写作要求的反馈检查](写作要求.md#标题与配图的反馈检查)，不新增平行规则。制作前为每张图写清主要信息、相对前图的增量、角色正在做什么及为何有用，先记录现成素材的采用/放弃理由，再生成或排版；与同类正反案例比较时保留原话和适用边界。新生成角色动作将实际提示词与身份参考纳入制作前字节绑定，不能只填“可爱、有科技感”等空泛方向。

交付检查逐图绑定成品及手机预览；生图、截图、来源原图与独立图解分清。重复角色身份可以保持品牌一致，但同一动作或画面再次出现须有新的解释作用，允许有意留白；不机械禁止跨页小猪，不在官方原图或固定母版上强加角色。文章无配图时说明原因，不用网页预览截图冒充文章配图。程序只核对记录和文件，角色身份、动作价值、可读性与真实性仍由Agent实际查看并负责。原成品变化后重做受影响的检查，不能沿用旧图的结论。

先按上节检查来源现成图片，再确定主视觉与细节配图各自的作用。通用自制主视觉按[具象小猪场景优先](#具象小猪场景优先2026-10-23)制作，需要新画面时使用图像生成技能；原帖、真实运行或输出截图保持实际内容，HTML/CSS适合结论、比较、关系、流程、步骤及嵌入真实截图的解释页。工具依画面职责选择，不用仿制界面替代真实结果。HTML贴图不套公众号长文复制排版参数，参考[贴图页面模板](模板/贴图页面模板.html)。

原始截图保留自然比例，可直接使用或等比嵌入图解页，不强制裁成 3:4。内容过密时拆页，不依靠持续缩小字号。真实界面截图不能由 HTML 仿制替代；命令行输出转排需明确标为“真实输出转排”，保存原始日志，不能标成原生终端截图。
