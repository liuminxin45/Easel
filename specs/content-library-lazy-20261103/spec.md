# 内容库摘要分页与逐层加载

用户已授权完整落实：首屏摘要每页50、游标分页、服务端搜索类型过滤、项目/版本/文件逐层读取；私有摘要索引后台构建及补偿，GET不全库扫描、不读历史正文/逐文件stat。原OutputsPage增加可选数据端口，默认官方行为不变，私有宿主注入；原预览/下载/鉴权保留，旧深链接直接定位，返回位置保留，页面外壳不等全树。缩略图按需生成，不为列表加载视频元数据。

索引为可重建派生数据，不改原库/资产/历史；后台复用原投影逻辑，共通模块不依赖私有层。摘要仅必要字段，游标绑定生成版本，新增/更新后台有界补偿。初建独立后台，旧索引在重建期间继续可用，原子切换。现有/api/outputs兼容合同保留，旧读取可回退。

验收目标：100/1000/10000项目TEMP，首屏工作量不随全库增长；50项<=100KB、正常本机P95<=1秒；分页/搜索/并发更新/缺失文件/权限/深链接/返回/慢网中断，原界面桌面与模拟移动端；实体vivo单列。独立健康中控只读索引进度与列表延迟/大小。提交自有fork、冻结配对、准入/队列/原数据核对后统一部署。状态：实施中。

正式基线实测：GET /api/outputs 49.563秒、4,313,008 bytes、277个根项目、17,037个节点。已确认首页同样全量读取，故同批将原DashboardPage增加可选摘要端口，默认官方行为保留，私有入口显示真实total及最近5条，外壳不等内容读取。

实现：独立data/content-library.sqlite原子重建，仅存节点元数据；初建及补偿复用原文件/业务投影，作品按更新时间/任务状态/产物数缓存相关根。源DB作品修订每5秒检查，物理目录和完整元数据每5分钟后台补偿；初建前台显示局部读取，已有索引重建期间前台继续读旧快照，不显示正常刷新提示。内容相同不改变generation；游标绑定query/parent/kind/generation，失效最多自动重启一次，避免循环。独立API /api/library/items和/resolve保留旧接口兼容；精确文件/版本/原生会话别名点查，不全树查找。认证媒体边界增加按需384px JPEG派生封面，原件仍由原预览/下载服务核验。
