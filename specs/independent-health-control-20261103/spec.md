# 独立健康中控与每日真实制作验证

用户授权：独立于项目运行、定时检查、安全自愈；每天允许一次真实采集与真实 Agent 制作贴图验证。此授权不包含采纳、发布、学习或重放未知请求。

目标：把入口存活、业务新鲜度、生产规模性能、真实制作分别验收，不能再以进程活着代替业务完成。中控使用项目外的独立 Python 环境、持久状态和 Windows 任务；不导入 Easel，项目丢失或依赖损坏时仍能记录故障。源代码在自有 fork 的 tools/health-control 维护，安装运行在 D:/Services/EaselHealthControl（实测 LocalAppData 被打包应用虚拟重定向，OS 任务不可依赖该别名）。

保留：官方页面/协议、正式数据、冻结版本、原始反馈、凭据引用、已受理操作身份；不清库、不自动采纳发布、不恢复退役功能。应用只提供集中诊断/恢复/最小 canary 导出端口，复用既有身份核验、停写围栏及原生执行链。

实施：
- 独立中控：nonce/PID/版本绑定、本机与 Tailscale 分层探测、业务/性能诊断、可审计报告；连续失败、冷却与重启预算持久化，操作先落盘，回执未知不重放。
- 安全恢复：仅核验进程身份且空闲时复用既有恢复机制；外部提供者失败、正常等待、慢请求不能直接触发整机重启。
- 每日 canary：独立数据目录，最多一次受理/日，实时采集与真实 Codex Agent 工具制作一张 PNG；严格 workspace-write、不复用正式会话、不复制完整数据库；核验真实文件、hash、准确版本与完成回执。当前不能声称已验证专用 AI 生图工具，真实工具绘图与专用生图区分报告。
- 性能：请求/数据库耗时、实际 backup 次数与字节、写事务占锁、并发争用；消除剩余只读预览整库复制。测试使用真实 SQLite 大库和争用，不能只 grep 源码。

验收：应用缺失/HTTP 超时/中控重启/PID 复用/上游500/忙碌任务/未知回执/重复日程故障注入；真实规模性能回归；首次真实 canary；独立任务实际运行及中控自恢复；自有 fork 提交推送与不可变版本部署。物理 vivo 未实测不得冒称验收。GitHub Actions 当前仓库禁用，日常检测不依赖云端 CI。
