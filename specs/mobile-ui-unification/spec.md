# 移动端全页与弹窗交互统一优化

Spec: mobile-ui-unification

## 目标与保留行为

逐页核查移动页面及弹窗，优先复用 Easel 原生组件，减少简陋提示与冗余控件；
验证后提交推送自有 fork，再部署上线。
官方基线 5a597e5，原 App/页面/组件/token 为唯一共通实现，不建立第二套视觉体系。
保留原始反馈、准确版本、草稿附件、未知回执身份和授权；修改、采纳、不采纳不自动制作或发布。
并行后端职责整理按独立 Spec 交付，不纳入本次前端切换。

## 实现

- 原新闻页复用既有 page-scroll，真实长文可滚到尾部和操作入口。
- 同一中断版本只保留一个 TaskStatus，历史状态附着消息/版本，不占固定顶部条幅。
- 技能详情/发布共用一个 Modal，差异就地展开，返回保持输入、范围、焦点和阅读位置。
- 菜单共用原 BrushItem；唯一 useBrushPopover 仅在实际越界/列表挤压时修正。
- 技能首次读取、空列表、错误明确区分；后台刷新保留已有卡片，不闪正常刷新提示。
- 共通主按钮 hover 只补原背景；必要公共修改不依赖私有业务，独立提交。
- 宿主仅适配移动几何，1024粗指针可操作收藏/编辑；不添加侧栏顶栏或第二套控件。
- 日期复用原生 datetime-local，未编辑不重写原值；未知保持原语义。
- 私有复盘去掉重复导航，草稿标题用内容或类型名，原键/原文保留。
- 私有弹窗宽屏补齐既有 header flex 几何，关闭按钮同排，原技能 Drawer 不改。
