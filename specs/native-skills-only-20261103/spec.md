# 技能体系采用 Easel 原生流程

## 用户决策

删除私有整理经验、候选、试用、版本发布与技能动作编排。保留业务技能作为普通项目 SKILL，全部使用官方列表、抽屉、配置、执行与结果流程。能力由工作流和 SKILL 自身组织，不再提供另一套私有制作方案流程。

## 实现边界

- 官方技能处理逻辑最小提取一次，两种入口共享；宿主只提供鉴权、CSRF、配置存储、原生引擎和持久请求身份。
- 新技能调用只需技能名与输入，不依赖私有版本、发布指针或动作表。历史已受理请求先查准确原回执，未知不重放。
- 当前经验提炼技能退役并归档；新写接口返回410，历史任务、技能版本、原文、作品、文件及冻结输入保留。
- 当前画像以准确预览SHA在停写期间新增修订，清除退役功能和私有版本pin；不覆盖旧修订。
- 当前七项业务SKILL改写成原生可调用指令，旧冻结包不变。普通技能产物沿官方outputs/和内容库呈现，不伪造私有采纳或交付回执。

## 验收与交付

源码单实现与依赖方向、原生接口契约、旧入口退役、幂等/未知回执、原件保存、普通项目技能发现和调用、桌面/窄屏明暗主题及所有技能弹窗。TEMP假引擎覆盖输入→原生执行→实际产物→继续修改，不能冒称真实模型质量。原入口与私有入口均检查构建；仅推自有fork，冻结同批前后端，经身份/空闲/队列检查后统一上线。实体vivo单独说明验证边界。
