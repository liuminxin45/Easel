# 私有技能对齐 Easel 写法

用户要求将八个私有技能整理为 Easel 常见的描述、画像、输入、流程和输出规范，并验证、提交自有 fork 和部署。沿用官方原生加载与画像注入，保留两个油猪流程、历史资源和明确授权边界；不改官方代码或已有冻结任务。

完成范围：PC-08、PC-09、PC-22～PC-27。元数据仅保持现有私有目录兼容，不宣称官方运行时把它作为参数校验。验证真实目录解析、画像消息构建、源文件字节及隔离浏览器；真实模型、人工采纳和发布分别报告。

用户追加要求：八项当前私有技能的显示名称统一以“油猪·”开头；技能 ID、历史记录及官方技能名称保持。技能卡、详情及原生选择器使用同一既有名称映射。
