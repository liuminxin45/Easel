# 会话创建可靠恢复与主体状态卡

用户要求完整落实已确认方案，修复手机WebToApp新建会话长期停在“恢复操作状态/正在打开原生对话”，选择异常使用页面主体状态卡，细节使用唯一官方Drawer。

已复现：一次执行前503被当成unknown，后续新建只GET旧回执永久waiting；恢复回执不接回草稿与导航。精确手机原始操作ID尚未取得，不能断言其最初触发是哪次部署/断网。

合同：X-Workbench-Operation-Protocol:2选择会话创建新协议；响应protocol_version、operation_id、operation_state、code/trace_id、完成result.session。执行前拒绝明确not_accepted，普通5xx/超时无证据仍未知。接受/运行持久化、完成会话与原业务回执同事务；超过1s返回202而非取消工作。重复先查原回执、原签名不变、准确画像/配置冻结。文件投影失败不撤销成功。服务重启只恢复元数据创建，不执行模型。

旧操作：POST /api/chat/sessions/operations/{operation_id}/resolve，正文request为原create请求、控制id独立。写事务核对已完成/已受理，否则按准确签名封存未创建旧命令。旧迟到请求同事务检查封存；resolve不创建会话、不调用模型，其他制作/发布未知不重放。前置拒绝保留原ID允许一次自动重试；封存旧ID后允许一次关联子命令，不能循环。

前端：独立session-open:<flowId>，持久化操作、画像、技能、来源、原草稿/附件引用、结果会话ID及应用进度。先保存准确完成身份、再清pending、再幂等应用草稿与navigation ticket；背景恢复与直接成功共用处理器；用户离开不抢导航。所有新建入口共用同一端口，不另写流程。401/退出不清草稿、输入，恢复不自动制作/发布。

展示：原card/btn/SVG/主题，最大480px，窄屏16px边距、44px触控，.ew私有布局；800ms前只按钮busy，超时主体卡；30秒后无持续旋转，可核对/详情/返回。无顶部重复纯文案。失败/未知不冒充断网，详细ID/版本/原因只进原Drawer；无独立Modal及全局CSS覆盖。

验收：执行前503后恢复、提交后丢响应、受理中重启、legacy不存在封存+迟到旧POST、操作并发、准确签名、元数据投影失败、杀WebView重开、401再登录、离开后恢复、多入口/画像、草稿附件原字。桌面/360/390/430与横屏明暗，TEMP真实HTTP/SQLite/浏览器存储，无模型；实体vivo单独标记。前后端及官方独立构建/架构技能检查，提交自有fork、冻结最终配对、准入/空闲/原生队列/历史表身份核对后部署，不推官方。

监测：前置拒绝和业务共享trace，安全元数据不含正文/凭据。独立中控加会话创建阶段年龄/失败计数；每天一次独立零模型浏览器journey，与原每日真实Agent身份/预算完全分离，不以HTTP存活冒充流程成功，不因客户端卡住重启全服务。
