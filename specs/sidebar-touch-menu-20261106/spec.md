# 移动侧栏会话长按菜单

用户批准实现并部署。移动触控布局隐藏常显的重命名/归档/删除按钮，长按约450ms显示会话操作；点击继续打开会话，移动超过8px或pointercancel取消手势，不妨碍垂直滚动。桌面保留官方hover按钮。

复用Sidebar现有重命名编辑器、归档和删除回调、图标、Drawer及宿主弹层栈；私有代码不复制会话业务或查DOM模拟隐藏按钮。共享Sidebar只提供可选条目呈现/操作端口，ResponsiveSidebar提供可选可见性通知并让嵌套对话框自行处理键盘，Drawer增加可选遮罩class供私有菜单使用视口遮罩和紧凑底部布局，默认布局与业务不变。私有菜单绑定准确会话，来源变化/关闭侧栏/导航时关闭；删除沿用原确认。

PC-02登记与差异台账同提交维护。验证触控点击/长按/拖动/取消/多指、归档与取消归档、原生重命名和删除确认、键盘/返回/焦点、明暗主题及桌面默认行为。浏览器旅程使用TEMP业务数据与假执行器，无真实模型或生产写入；实体vivo未操作。通过前端检查、双构建、相关架构检查后推送自有fork，冻结配对并经空闲准入部署。
